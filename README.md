## 📌 Overview
This repository contains my solutions for the **Week 8 Assignment** in the PLP Academy [Database Systems](https://academy.powerlearnprojectafrica.org/module/6a259fb4911523cdf74594d3?study=false) module. The project demonstrates practical command-line database management skills using the `mysqldump` utility to perform single-database backups, full server backups, and disaster recovery preparations.

---

## 🎯 Learning Objectives
- Understand the fundamental importance of database backup and recovery in production environments.
- Use `mysqldump` to create complete backups of specific databases (e.g., the `sales` database).
- Execute server-wide exports of all databases prior to server migrations.
- Implement robust backup strategies to support disaster recovery and data continuity.
